把模型接入你的客户端

创建账号、充值积分并生成 API Key 后，在客户端填写 API Base、API Key 和模型名。

密钥只保存在你自己的客户端中。向配置助手求助时，使用 YOUR_API_KEY 占位符，删除日志和截图中的密钥。

连接参数

OpenAI 兼容 API Base请在首页核对运营方公布的地址。
API Key控制台 → API 密钥 → 创建 Key。明文仅显示一次。
模型名复制首页已公布的模型名，或查询 GET /v1/models。

部分客户端要求 API Base 包含 /v1，另一些会自动添加。请先核对客户端文档，避免出现 /v1/v1。Claude Messages、Gemini 原生客户端使用各自的协议路径，需要核对客户端是否允许自定义服务地址。

先用一个文本请求验证

把示例地址和模型名替换为首页公布的值。把密钥放入你本机的环境变量，避免写入代码或分享记录。

curl https://api.example.com/v1/chat/completions \
  -H "Authorization: Bearer $CPA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"MODEL_FROM_PRICE_LIST","messages":[{"role":"user","content":"你好"}],"max_tokens":64}'

积分如何计算

CNY 和 USDT 是付款币种，分别按管理员设置的兑换率换成同一种积分。创建订单时保存兑换率和到账积分，之后调整兑换率不会改变旧订单。

模型价格以每 100 万 token 的积分数展示。输入、输出、缓存读取和缓存写入分别计费；缓存价格为 0 表示该项免费。价格修改适用于新请求，用量记录保留计费版本。历史货币余额需先由管理员对账。

常见错误

现象检查项目
401密钥是否完整、有效，是否被撤销；Authorization 是否使用 Bearer。
402积分是否充足；充值订单是否已确认。
403模型是否已上架并定价；账户与当前 API Key 是否允许使用该模型。
404API Base、协议路径，以及客户端是否重复添加 /v1。
429降低并发并按 Retry-After 重试；助手每日次数用尽后次日再试。
503配置或计费服务暂时不可用。稍后重试并联系运营方。

配置助手

登录后打开“配置助手”，说明客户端名称、版本、已填写的 API Base 和脱敏错误信息。助手开放状态由运营方决定，次数和输出长度有限。助手不能修改你的设备，回答需要结合客户端官方文档核对。

付费接口当前要求通过 JSON 或模型 URL 明确指定模型；无法在执行前绑定价格的 WebSocket 和 multipart 请求暂不开放付费调用。
